# ⌨️ Typing Speed Test in C

A simple and interactive **Typing Speed Test** application built using the C programming language. This project measures typing speed, accuracy, and time taken to type a given sentence.

## ✨ Features

- ⏱️ Measures typing time.
- 🚀 Calculates typing speed in Words Per Minute (WPM).
- 🎯 Calculates typing accuracy percentage.
- 📝 Counts correctly typed characters.
- 🏆 Displays performance feedback based on accuracy.

## 🛠️ Technologies Used

- 💻 C Programming
- 📚 Standard C Libraries:
  - `stdio.h`
  - `string.h`
  - `time.h`

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project in VS Code or any C compiler.
3. Compile the source code:

   ```bash
   gcc typing_speed.c -o TypingSpeedTest
   ```

4. Run the program:

   **Windows:**
   ```bash
   TypingSpeedTest.exe
   ```

   **Linux/macOS:**
   ```bash
   ./TypingSpeedTest
   ```
